## Collaboration / Level 1+ access

If you are a researcher interested in access to non-public components
(per-annotation ontology metadata, span positions, surface text, source
identifiers), please reach out with:

1. Institutional affiliation
2. Intended research use
3. IRB / ethics approval status (where applicable)
4. Confirmation that data will be used only for the stated purpose
5. Agreement to non-redistribution terms

If you believe any content in this repository inadvertently exposes
material that should not be public (e.g., surface text, identifiers,
patient information), please open a GitHub Issue or email the contact
above as soon as possible. We will respond promptly.
